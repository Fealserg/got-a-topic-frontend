# Пачка 2. Весь интерфейс

Когда брать эту пачку: в продукте есть не только форма, но и списки, пустые экраны, загрузка, мобильный вид и ошибки сети. Команда хочет один файл на любой агент, не только на Cursor.

Не брать вместе с пачкой 1. Одного файла достаточно.

Куда положить: `docs/ux-interfeys.md` в репозитории команды. В первом сообщении агенту прямо указать этот файл.

Опора: практические правила для Next.js и Tailwind из [ux-guidelines](https://github.com/manikandan-22/ux-guidelines). Текст ниже ужат под хакатон: без заморозки колонок, выгрузки CSV и корпоративных таблиц.

Стек: Next.js, Tailwind CSS, shadcn/ui, иконки Lucide. Экраны и данные берутся из контекстного документа команды. Этот файл говорит, как их показать.

## Формы

- Поля идут в один столбец. В одну строку только короткая связанная пара: индекс и город, месяц и год.
- У каждого поля видимый `<label>`, связанный с полем. Placeholder подписью не является.
- Обязательность показывают одним способом на всю форму: либо звёздочка у обязательных, либо слово «необязательно» у остальных.
- Ошибку поля показывают на потере фокуса, не на каждый символ и не только в момент отправки. Исправление снимает ошибку сразу.
- Ошибка стоит рядом с полем и говорит, что не так и что сделать. Выключенная кнопка сама это не объясняет.
- Из-за одной ошибки не очищать введённое. Обрыв сети не выбрасывает черновик.
- У многошаговой формы виден шаг «текущий из всего». Уход со страницы с несохранённым вводом предупреждают.
- У почты `type="email"`, у телефона `type="tel"` и цифровая клавиатура. Знакомым полям ставят `autocomplete`.
- Значение, которое видно, но нельзя менять, помечают `readonly`, а не прячут.

## Кнопки и контролы

- На экране одна главная кнопка. Остальные спокойнее.
- Текст кнопки не переносится и не обрезается. На ней написано действие.
- Кликабельное не меньше 44×44 пикселей, между целями есть зазор.
- У интерактивного элемента видны наведение и нажатие. У иконки без текста есть подпись для скринридера.
- Необратимое действие спрашивают подтверждение. То, что можно отменить, можно закрыть сообщением с отменой, без лишнего диалога.
- Список длиннее десяти пунктов можно искать, а не листать целиком.

## Состояния

- Пустой список говорит, что именно пусто и что сделать. Не писать голое «Нет данных».
- Пока данные грузятся, показывают скелет, не белый экран.
- Действие получает отклик в пределах 400 мс. Если дольше, виден прогресс.
- Успех и ошибка названы конкретно: что произошло и что можно сделать дальше. Не «Success» и не код ошибки.
- Короткое обратимое действие можно показать сразу, не дожидаясь ответа сервера, если откат понятен.

## Раскладка и мобильный

- Страница не прилипает к краям. На широком экране колонка контента ограничена и стоит по центру.
- Близкое по смыслу ближе друг к другу, чужие блоки дальше.
- Экран работает на ширине телефона. Всё, что завязано только на наведение, дублируют нажатием.
- Поле при фокусе не прячется под клавиатуру.

## Доступность

- Контраст текста не ниже WCAG AA: обычный текст около 4.5:1, крупные элементы и значки около 3:1.
- Смысл не кодируют только цветом.
- Фокус виден. Обводку не убирают, не заменив её.
- Картинка со смыслом имеет текст вместо неё. Декоративная картинка его не имеет.
- Диалог ловит фокус и возвращает его туда, откуда открыли. Второй диалог поверх первого не открывают.
