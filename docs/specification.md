# ТЗ Frontend · Есть тема

Независимый репозиторий Next.js + TypeScript. Все бизнес-действия обращаются к отдельному FastAPI через серверный proxy `/api/*`. `API_BASE_URL` читается во время запроса, поэтому образ не привязан к одному адресу backend. Нельзя передавать backend origin из пользовательских параметров.

## Экраны

- Лендинг: ценность, целевое действие «Найти своего собеседника», три шага, описание пользы, вход/регистрация. Демо-вход только при флаге сервера.
- Регистрация/вход: имя при регистрации, логин, пароль, добровольное согласие, предупреждение об отсутствии восстановления; ошибки сервера без потери формы.
- Профиль: имя, роль, компания, описание, запросы, опыт, перерывы, видимость; сохранение и удаление с подтверждением.
- Подбор: карточки участников, причина совпадения, демо-метка, свободное время, поиск по имени/роли/компании, фильтр темы, обновление.
- Приглашение: общая тема, доступный интервал, место, необязательное сообщение, отправка. Информация о демо-собеседнике.
- Мои встречи: входящие и исходящие, статусы, тема, время/место, принятие/отказ/отмена по правам. После окончания — оценка факта и пользы.
- Организатор: только для серверного is_admin; агрегированные показатели с исключением демо, создание будущего 15-минутного интервала без пересечений.

## UX

Русский интерфейс, утверждённое название «Есть тема», спокойная зелёная палитра, карточки собеседников. Ориентир — быстро найти конкретного человека и договориться, без социальной ленты. Адаптивность: боковая навигация на desktop, верхняя на телефоне; сетка 3/2/1 колонки. Время явно по Москве. Модальные окна используют native dialog, клавишу Escape, блокировку фонового фокуса и возврат фокуса.

Загрузка, пустой подбор, скрытый профиль, отсутствие будущего времени, ошибка сети/API, успех сохранения/приглашения и конфликт времени показываются явно. Ничего не сохраняется как будто успешно при ошибке API. Контакты не собираются и не публикуются. Профили и слоты демо помечены.

## Проверки

TypeScript strict и production build. Браузерный сценарий: регистрация → профиль → рекомендация → приглашение → вход получателя → принятие → встреча у обеих сторон. Проверить размер 390×844, отсутствие горизонтального скролла, доступность полей и обработку ошибки API. Демо не считается реальным пилотом.

## Уточнения после сверки с инструкцией

Адрес backend валидируется внутри защищённого блока proxy. В production API_BASE_URL обязателен; заглушка платформы, credentials в URL и пути вместо origin дают безопасный 502. Справочный контракт хранится в `docs/openapi.json` каждого репозитория.

Регистрация, профиль, приглашение и создание времени используют общую валидацию полей при потере фокуса; исправление убирает ошибку. Серверные field errors привязываются к полям. Несохранённый профиль защищён подтверждением при переходе/выходе и beforeunload при закрытии вкладки. Кликабельные контролы имеют минимум 44px. Выбрана UX-пачка `docs/ux-interfeys.md`.
