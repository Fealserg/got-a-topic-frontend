Есть тема — комплект сдачи без видео

Распакуйте ZIP и откройте index.html. Интернет нужен только для ссылок на приложение, Swagger и GitHub.
Документы: *.html. Редактируемые источники: sources/*.md. Готовые схемы: assets/*.svg.
Контракт: openapi.json. Свидетельства проверок: evidence/. Манифест: manifest.json.
Код: code/frontend-source.zip и code/backend-source.zip. Речь: demo-script.html. Чек-лист: readiness.html.
Публикация: загрузить распакованную папку и ZIP на облачный диск с открытым чтением/скачиванием либо включить GitHub Pages для содержимого папки.
Видео исключено по поручению пользователя. Публикация и отправка формы этим архивом не выполняются.
